网吧离线包 · 操作流程

  一句话：把 index.html 弄到网吧电脑上，双击就能玩；下机前把存档导出成文件发给自己，换台机器导入接着玩。
  不安装、不联网、不登录、不需要微信开发者工具。

零、包里有什么

 文件     用途 
 index.html     游戏本体，单文件约 220 KB，双击即玩，所有画面都是代码画的，不加载任何外部图片或脚本 
 README.txt     本说明的纯文本版（记事本可直接打开） 
 PROJECT.txt     项目简介 
 CHECKSUM.txt     文件大小与 SHA256，用来确认上传/下载没损坏 
 save-panel.png     存档按钮长什么样，第一次用可以对照 

一、把游戏弄进网吧（三选一）

A. 网盘 / 微信文件传输助手（最推荐）

网吧常常禁用 U 盘，这条最稳。

1. 在家把整个 ZIP 上传到网盘，或直接把 index.html 发给「微信文件传输助手」/ 自己的 QQ。
2. 到网吧，登录网页版网盘 / 微信，把 index.html 下载到桌面。
3. 如果只想要一个文件，只传 index.html 就够了。

B. U 盘

1. 把 index.html 拷进 U 盘。
2. 网吧机插上，复制到桌面（不要直接在 U 盘里双击，有些机器会拦）。
3. 拔 U 盘前记得先把存档文件拷回去（见第三节）。

C. 自己上传到静态空间，用网址玩（最省事，一次上传长期用）

游戏是纯静态单文件，只要能放一个 HTML 的地方都能托管：

  * GitHub Pages
  1. 在 GitHub 新建仓库（公开即可），上传 index.html 到根目录。
  2. 仓库 → Settings → Pages → Source 选 main 分支 / root → Save。
  3. 等一两分钟，打开 https://<用户名>.github.io/<仓库名>/ 就能玩。
  4. 以后在任何网吧只要记住这个网址，不用带文件。
  * 对象存储 / 自己的服务器 / 任意静态托管：把 index.html 放到网站根目录，确保返回 Content-Type: text/html; charset=utf-8 即可。
  * 注意：网址玩的时候进度存在「这台电脑的这个浏览器」里，换机照样要导出/导入存档；网址本身不保存你的进度。

  如果传的是整个 ZIP，也可以先把 ZIP 传到网盘，网吧下载后解压到桌面再用。

二、上机：开始玩

1. 开机，打开 Edge 或 Chrome（IE / 老旧浏览器打不开，页面需要 HTML5 + SVG）。
2. 双击桌面上的 index.html；若没反应，右键 → 打开方式 → 选 Edge / Chrome，或把文件直接拖进浏览器窗口。
3. 首次进入是「开宗门」页：填宗门名，选路数、长老、道侣，点 开门。
4. 中间的大圆是游历，点一下走 15 天，常会撞见三选一事件；左右是签到、机缘、一键突破、游历设置；底部五宫格是排行 / 布阵 / 游历 / 洞府 / 世界。
5. 画面不全或字太大：按 Ctrl + 0 恢复缩放；窗口拉成竖长比例观感最好。
6. 进度会自动存在本机浏览器里，但网吧有还原卡，重启就没了——所以下机前必须做下一节。

三、下机：把进度带走（每次都要做）

1. 点右下 「游历设置」（齿轮「设」），往下拉到 「存 档 / 换 机 续 玩」。
2. 点 「导出存档文件」，浏览器会下载一个 破山门_存档_日期_时间.txt。
  * 若提示「不让下载」：点 「复制框里存档码」，把那串文字粘到网盘笔记 / 备忘录里（存档码比较长，聊天框可能被截断，优先用文件）。
3. 把这个 .txt 发给自己：微信文件传输助手、QQ 我的设备、网盘、U 盘都行。建议文件名带上日期，别覆盖上一份。
4. 点 「清空本机记录」，然后直接关掉浏览器。这样下一个人打开是全新一局，看不到你的宗门。
5. 结账下机。

  顺序记成一句话：导出 → 发给自己 → 清空 → 关浏览器。

四、换一台机器：接着玩

1. 重新打开 index.html（或你上传的网址）。
2. 如果显示的是全新开局界面，先别急着开门（开了会覆盖，但还能再导入，不影响）。
3. 进 游历设置 → 存档 / 换机续玩：
  * 有存档文件：点 「导入存档文件」，选刚才那个 .txt；
  * 只有存档码：把码粘进文本框，点 「用框里的码导入」。
4. 出现「存档读回来了，接着玩」就成功了，仙历、弟子、建筑、彩蛋都会回到下机前的状态。
5. 下次下机重复第三节。

五、常见问题

 现象     怎么办 
 双击没反应 / 一片空白     右键用 Edge / Chrome 打开，或拖进浏览器；确认文件没被改成 .html.txt 
 浏览器提示「已阻止下载」     点地址栏右侧的下载拦截 → 允许；或换桌面为下载目录；实在不行用「复制存档码」 
 每次开机进度都没了     正常，网吧有还原卡。必须用导出 / 导入，不能指望自动存档 
 页面提示「这台电脑不能自动存档」     本机 localStorage 被禁。照常用，但下机前一定要导出文件 
 导入时提示「不是本游戏存档，或版本对不上」     拿错文件了，或是旧版本包的存档。用同一版离线包重新导出；极老的档不兼容 
 存档码太长发不出去     正常，玩久了十几 KB。改用 .txt 文件，别用聊天文本 
 存档文件被网盘当风险文件 / 被清理     内容是纯文本，可改名为 笔记.txt；或压缩一下再传 
 网吧禁止往网页传文件     用「复制框里存档码」，粘到网盘笔记；下次复制回来粘进文本框导入 
 界面元素重叠 / 按钮点不到     Ctrl + 0 恢复 100% 缩放，或把浏览器窗口拉高 
 担心别人看到我的进度     下机前点「清空本机记录」并关掉浏览器；游戏不联网、不登录，没有账号信息 
 用网址玩，换浏览器后进度没了     进度按「浏览器 + 域名」隔离，换浏览器等于换机器，用导出/导入 

六、安全与隐私

  * 游戏不联网、不上传任何数据，存档只在你本机和你自己保存的文件里。
  * 存档文件是明文 JSON，别在公用电脑上留副本；清空本机记录后再走。
  * 不建议在网吧浏览器里登录网盘后忘记退出，传完文件记得退出登录。
  * 导出的存档可以自己改（明文 JSON），改坏了顶多读不回来，不会影响别人。

七、确认文件没坏

打开 CHECKSUM.txt，里面写了 index.html 的字节数和 SHA256。在 Windows PowerShell 里核对：


    Get-FileHash .\index.html -Algorithm SHA256


哈希一致就说明下载/上传过程没损坏。若不一致，重新下载一份。
